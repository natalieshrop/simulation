# Simulation- Data Breach Leading to a Terrorist attack

This project is a web-based simulation platform designed to teach participants how local and federal government agencies collaborate to address a multi-faceted domestic terrorist threat. It incorporates scenarios involving cyber breaches, espionage, hate crimes, and threats to critical infrastructure like the U.S. Capitol Building.

This project is useful becasue it 
- promotes understanding of interagency operationg
- encourages collaborative problem-solving
- enhances particiaptn knowledge of cybsersecurity
- teaches real-world government roles and decision making
- supports educational goals in political science, national security, public safety, and cyber defense
